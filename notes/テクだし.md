# テクだし

チューリングマシンのデモで使える技術と表現アイデアの洗い出し。採用・却下を決めたら、理由を添えて「判断」欄に書く。

## 1. 実装プラットフォーム

| 候補 | 長所 | 短所 |
|---|---|---|
| Web（TypeScript + Canvas2D / p5.js） | 共有しやすい。すぐ作れる。UI も作りやすい | 大規模な描画には弱い |
| Web（Three.js / WebGPU） | 3D 表現ができる。ブラウザで動く | 実装コストが中くらい |
| Unity（URP + VFX Graph / Compute Shader） | 高品質な 3D・パーティクル。展示向き | 配布が重い。UI は UI Toolkit などで別途作る |
| TouchDesigner | インスタレーションや音との連携が速い | ロジックの記述がしづらい |
| Houdini | 時空間図をジオメトリとして造形・レンダリングできる | リアルタイムのデモには向かない（映像向き） |

## 2. コアロジック

- 遷移表のデータ形式: JSON / YAML / 簡易 DSL（例: `A,0 -> 1,R,B`）
- テープ: `Map<int, symbol>` を使った疎な表現、または中心からの両方向配列
- ステップ実行と描画を分ける（決まった刻みで論理ステップ → 補間しながら描画）
- 高速モード: 描画を間引いて N ステップずつ一気に進める。Busy Beaver(4) は 107 ステップ、BB(5) は約 4,700 万ステップ
- GPU 化: 1 台では逐次処理なので向かない。多数のマシンを並列に走らせる場合（ランダムな遷移表の探索など）は Compute Shader が使える

## 3. 可視化アイデア

- **テープ + ヘッド**: 横に並んだセルと、上下に動くヘッド。基本形
- **時空間図**: 1 ステップで 1 行ずつ縦に積む。セル・オートマトン風の模様になる
- **3D 時空間**: 時間を奥行き方向に押し出し、ボクセルや柱として造形する
- **状態遷移グラフ**: ノード = 状態、エッジ = 規則。今の遷移を光らせる
- **物理メタファー**: テープを機械的なベルトやリールとして見せる。書き込みをスタンプ／パンチ穴で表す
- **色**: 状態ごとに色を変え、ヘッドの軌跡に状態の色を残す

## 4. インタラクション

- 再生・一時停止・ステップ・速度スライダー
- 遷移表エディタ（表形式で、その場で反映）
- テープの初期値入力
- プリセット切り替え

## 5. サウンド（任意）

- 記号の読み書きでクリック音、状態ごとに音程を変える
- 状態遷移をシーケンサーとして扱い、Ableton と連携する（MIDI / OSC）

## 6. 参考になる題材

- Busy Beaver 問題（停止するまでのステップ数が最大のマシン）
- 万能チューリングマシン（ほかのマシンをテープ上でシミュレートする）
- Langton's Ant（2 次元版の Turmite）への拡張

## 判断

| 日付 | 項目 | 結論 | 理由 |
|---|---|---|---|
| 2026-11-23 | プラットフォーム | Web（素の JS + Canvas2D）を採用 | GitHub Pages で公開するため。学習用なので 3D より分かりやすさを優先 |
| 2026-11-23 | ビルドツール（Vite・TypeScript） | 使わない | Pages にそのまま置ける。規模が小さく、型の恩恵より手軽さを優先 |
| 2026-11-23 | Unity / TouchDesigner / Houdini | 今回は使わない | Web 公開と相性が悪い。展示版を作るときに改めて検討する |
| 2026-11-23 | 可視化 | テープ + ヘッド、時空間図、遷移表のハイライト、説明文を採用 | 「なぜそう動いたか」を規則と結びつけて見せるため |
| 2026-11-23 | 状態遷移図の配置 | 円形配置は却下。開始状態からの距離で列に分け、例題は手で配置を決める | 円形だと矢印が中央に集まり、ラベルが重なって読めなかった |
| 2026-11-23 | 行の並べ替え | HTML5 の Drag and Drop API ではなく Pointer Events で自作する | HTML5 の DnD はタッチ操作で動かないため |
| 2026-11-23 | 遷移表の形式 | 表形式のエディタ。共有は JSON を base64url にして URL ハッシュへ | テキスト DSL より初学者に分かりやすい |
