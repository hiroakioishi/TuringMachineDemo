# 仕様

> ステータス: v1 実装済み

## 目的

- チューリングマシンの動作（テープ・ヘッド・状態遷移）を、見て分かる形で表現する。
- 見せる相手: **学習・説明用**（チューリングマシンを初めて学ぶ人）
- 公開先: **GitHub Pages**

## チューリングマシンのモデル

- テープ: 両方向に無限の 1 次元テープ（表示は有限の窓）
- 記号: 任意の 1 文字。空白記号はマシンごとに設定（既定は `_`、ビジービーバーは `0`）
- ヘッド: 1 マスを読み書きし、L（左）/ R（右）/ N（動かない）に移動
- 状態: 任意の名前。開始状態は 1 つ、停止状態は複数可
- 遷移表: `(状態, 読んだ記号) → (書く記号, 移動方向, 次の状態)`
- 停止条件: 停止状態になったとき、または当てはまる規則がないとき

## 機能

- [x] 例題の切り替え（ビット反転、2 進数に 1 を足す、1 進数の足し算、回文の判定、ビジービーバー 2・3・4 状態）
- [x] 1 ステップ進む・戻る・連続再生・一時停止・リセット
- [x] 速さの調整（0.5〜64 回/秒、最速。スライダーと「遅く」「速く」ボタン、− / ＋ キー）
- [x] 現在の状態の表示（状態チップ、ヘッド上のラベル。状態ごとに色分け）
- [x] 遷移表のハイライト（次に使う規則／直前に使った規則）
- [x] ステップごとの説明文（何を読み、どの規則で、何を書き、どこへ動いたか）
- [x] 時空間図
- [x] 状態遷移図（SVG。現在の状態を塗りつぶし、次に使う規則／直前に使った規則の矢印を強調。状態はドラッグで配置を変えられ、「配置を戻す」で元に戻る。配置は共有リンクに含まれる）
- [x] 遷移表の行の並べ替え（⠿ をドラッグ。マウス・タッチ両対応。⠿ を選んで ↑↓ キーでも移動できる）
- [x] 遷移表の編集（行の追加・削除、その場で反映、誤りを赤枠と一覧で表示）
- [x] 設定の編集（初期テープ、ヘッドの開始位置、空白記号、開始状態、停止状態）。変えるとリセット
- [x] 共有リンク（URL のハッシュ `#m=` に設定と遷移表を保存）
- [x] 「チューリングマシンとは？」の解説、キーボード操作（Space / ← / → / R）
- [x] 解説の部品カード（テープ・ヘッド・状態・遷移表）をクリックすると、その部品までスクロールしてスポットライトで示す（ほかを暗くし、脈打つ枠と説明ラベルを表示。ヘッドなどは Canvas 上でも枠を表示。6 秒、または画面クリック・Esc で解除）
- [x] ライト／ダークモード、スマートフォンの画面幅に対応

## 画面構成

- 左（狭い画面では上）: 例題の選択、テープとヘッド、操作ボタン、統計、状態、説明文、状態遷移図、時空間図
- 右（狭い画面では下）: マシンの設定、遷移表エディタ
- 下: 解説
