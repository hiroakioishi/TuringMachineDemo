# チューリングマシン・デモ

チューリングマシンのテープ・ヘッド・状態・遷移表のしくみを、1 ステップずつ動かして学べる Web デモです。

- 1 ステップずつ進める／戻す、連続再生、速さの調整
- 各ステップで「何を読み、どの規則で、何を書き、どこへ動いたか」を文章で説明
- 遷移表の編集（その場で反映、入力の誤りを表示）
- 時空間図（テープの変化の履歴）
- 例題：ビット反転、2 進数に 1 を足す、1 進数の足し算、回文の判定、ビジービーバー（2〜4 状態）
- 共有リンク（マシンの設定と遷移表を URL に保存）

## ローカルで動かす

ES モジュールを使っているため、`index.html` を直接開くのではなく、ローカルサーバー経由で開きます。

```powershell
python -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

## テスト

コアロジック（`js/machine.js`）と例題のテストを Node.js（18 以上）で実行します。

```powershell
npm test
```

## GitHub Pages で公開する

ビルドは不要です。リポジトリのルートにあるファイルがそのまま公開されます。

1. GitHub にリポジトリを作成し、このフォルダーの内容を push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、**Branch** を `main` / `(root)` にして保存する
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## ファイル構成

| パス | 内容 |
|---|---|
| `index.html` | ページ本体 |
| `css/style.css` | スタイル（ライト／ダーク対応） |
| `js/machine.js` | チューリングマシンのコア（検証・実行・巻き戻し）。DOM に依存しない |
| `js/presets.js` | 例題 |
| `js/render.js` | Canvas 描画（テープとヘッド、時空間図） |
| `js/main.js` | UI（操作、遷移表エディタ、共有リンク） |
| `tests/` | Node.js のテスト |
| `notes/` | 仕様・進捗・技術メモ |
